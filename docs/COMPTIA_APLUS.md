# CompTIA A+ study area (Core 1 220-1201 and Core 2 220-1202)

A study aid inside the IT Specialist track (IT dashboard > **CompTIA A+**). It follows the public exam-objective documents, version 2.0, but every question, table and tool is written for this project. It is **not affiliated with CompTIA and is not the exam**: use CompTIA's current objectives and an official practice exam as the final check.

## What is in it
| Part | What it does | Honest limit |
|---|---|---|
| Objective map | All 63 objectives (27 Core 1, 36 Core 2) with the exam's domain weights. Rate each 0 to 3; readiness is weighted like the exam, 60% self-rating and 40% practice results, and it names the domain to study next. | A guide, not a prediction. |
| Practice questions | 94 scenario questions across every domain, graded on the server with a reason for every answer. Results are kept per domain. | Smaller than a real bank; a high score does not predict a pass. |
| Drills | Port flashcards and acronym flashcards from both lists. | Memory aids only. |
| Symptom finder | Search symptoms for the troubleshooting objectives (Core 1 5.1 to 5.6, Core 2 3.1 to 3.4): likely causes and first checks, in the six-step method. | A starting point, not a diagnosis. |
| Tools | IP address check (APIPA, private, public, mask and gateway sanity), DHCP scope planner (pool, exclusions, reservations, lease), SPF/DKIM/DMARC record checker, display calculator, power supply sizer, backup planner (full, incremental, differential, synthetic; 3-2-1), script reviewer. | Fixed rules and exact arithmetic with assumptions printed. The mail checker reads pasted text, not live DNS. The script reviewer never runs the script. |
| Reference | Wi-Fi, network hardware, cables, hardware, printers, mobile, cloud, Windows tools and commands, macOS and Linux, security, operations. | Condensed; check the objectives for the full list. |
| Checklists | Added to the IT Checklists tab: SOHO malware removal (2.6), making a change safely (4.2), retiring a drive (2.9) and the troubleshooting method. Qual template: Change request. | |

## What needs real hardware
Replacing a battery, reseating RAM, crimping and testing cable, using a Mac, and learning Linux on a real machine cannot be done on a screen. The map marks these "needs real hardware or an OS". Use a spare PC, a cheap cable kit and a Linux live USB.

## Mistakes in CompTIA's acronym lists (corrected here)
CAC is the Common Access Card (the list says "Calling-card Authorization Computer"); WISP is a *wireless* ISP (the list says "Written"); HDMI is High-Definition *Multimedia* Interface (Core 2 says "Media" in one place); VNC is Virtual Network *Computing*; RADIUS ends in *Service*, not "Server"; SAML is Security *Assertion* Markup Language; the Core 1 list gives a different SPICE (a process-improvement standard) from the Simple Protocol for Independent Computing Environments used in the Core 2 objective; AAAA in the DNS objective is the IPv6 record but the list expands it as an auth term; and "XXS" should be XSS.
