# Work mode and Learn mode

The dashboard has two modes, switched with the button in the top corner. The choice is remembered in this browser.

**Work mode (default)** shows only what you use to earn money: Home, Clients, Services (with the Henderson and Las Vegas price list), Data, Dashboards, Fields and More.
Every learning page is hidden. If you open one by link, you see a prompt to switch. Nothing is deleted.

**Learn mode** shows Tracks, Quiz, Review, Glossary, the labs (SQL, Analysis, Model Studio, NLP and Deep Learning, Systems Design, Diagram studio, Practice vs Real), the practice pages,
the how-to guides, and the Fields menu with its study tabs (how-to search, simulators, cheat sheets, exam prep).

**Fields.** The Fields button opens a main screen of field cards, grouped Data, Tech, AI and Research, and Business. Each card opens that field's own dashboard: its tools, plus the services you can sell in it with prices. IT repair, Network and Cybersecurity keep their track dashboards. The Fields menu jumps straight to any field. In Settings, "Mode and my fields" lets you tick only the fields you sell.
In Work mode the field pages leave out how-to search tabs, learning paths, simulators and exam prep. The job tools stay, including How to repair (IT) and How to fix (security).

**Price list.** Services has a second view with the researched price list. Hourly rates in the catalog start from it; change them any time.
