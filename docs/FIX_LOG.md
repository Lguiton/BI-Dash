# Fix log

Every fix you make can be written down once and found again. It works for IT repair, Cybersecurity and Network (a "Fix log" tab in each).

- **Have I fixed this before?** Type the problem in your own words. You get your past fixes with their steps and result, plus the built-in guides on the same words.
  It matches words, spelling variants and related words, not meaning, so write records in the words you would search with.
- **Write a fix down.** Title, device, symptoms, cause, steps taken, result, minutes, tools or parts, prevention, client, tags.
- **From a ticket.** In the IT Helpdesk, "Save this fix to the fix log" starts a record from the steps you ticked and the notes you added. Edit, then save. The ticket gets a note linking to it.
- **Seen before.** Opening or viewing a ticket shows past fixes that look similar.
- **Write-ups.** Markdown for you, an HTML client copy that leaves out internal cause notes, and a printable page of the whole log.
- **Safety.** Passwords, API keys, tokens and private keys are blanked before saving. Write what you did, not the secret.

Records live in the app's database for the active workspace. Backups include them.
